
# DocumentationPractice

## Deskripsi
DocumentationPractice adalah proyek Java sederhana
untuk mempelajari dokumentasi program dan penggunaan
README dalam pengembangan perangkat lunak.

## Tujuan
- Memahami struktur program Java.
- Menjelaskan fungsi kelas dan method.
- Menyediakan panduan penggunaan program.

## Persyaratan
- Java Development Kit (JDK)
- IntelliJ IDEA atau IDE Java lainnya

## Cara Menjalankan
1. Buka proyek DocumentationPractice di IntelliJ IDEA.
2. Pastikan JDK sudah dikonfigurasi.
3. Buka kelas yang berisi method main().
4. Klik tombol Run.
5. Amati hasil program pada console.
